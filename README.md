# 🚗 India Cars AI Assistant

An interactive automobile knowledge platform covering Indian cars sold between 2000 and 2026.

The project combines a Python-powered conversational search engine with a modern web interface to help users explore vehicle specifications, compare models, discover recommendations, and retrieve information using natural language queries.

Unlike traditional AI applications that depend on external APIs, this project uses a fully embedded knowledge base and rule-based search logic, allowing it to operate completely offline.
